Área Administrativa

Acesso restrito para administradores autorizados

Acesso Restrito: Esta área é destinada apenas para administradores autorizados. Para solicitar acesso ou reportar correções nos dados, entre em contato através dos canais oficiais.

Funcionalidades disponíveis para administradores:

  • Atualização de dados dos conselhos municipais
  • Correção de informações de municípios
  • Adição de novos conselhos
  • Gestão de dados de estabelecimentos
